# Scanner and Parser Projects
## Submitted by Jerold Aquino and Andre Dorde.

### How to makefile
`make test` allows for the compiling of both scanner and parser,
as well as getting all the .txt files from the Input folder
and making their respective outputs under Output folder.

`make all` to compile scanner.exe and parser.exe.

`make test-scanner` and `make test-parser` compiles only
their respective modules, including their outputs.

`./scanner.exe file_name.txt` can be used to scan only one input file.
`./parser.exe file_name.txt` can be used to parse only one input file.
